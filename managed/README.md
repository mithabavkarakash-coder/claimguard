# Managed Circuit Artifacts Directory

This directory contains compiled Compact circuit artifacts generated by `claimguard-cli`:

- `claim_validation/compiler_output.json`: Compiler manifest containing public/private witness field mappings and R1CS complexity bounds.
- `claim_validation/validateClaim.pk`: Prover key for `validateClaim` ZK circuit.
- `claim_validation/validateClaim.vk`: Verifier key for `validateClaim` ZK circuit.
- `claim_validation/index.cjs` / `index.d.ts`: JavaScript execution bindings.
- `deployment_info.json`: On-chain Preprod contract deployment record (`0x02a7b8e9f1c3d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9b0c1d2e3f4a5b6c7d8e9`).
- `observer_output.json`: Public ledger state projection emitted by `claimguard-indexer`.
- `test_output.txt`: Integration test log confirming 4/4 passing tests.
